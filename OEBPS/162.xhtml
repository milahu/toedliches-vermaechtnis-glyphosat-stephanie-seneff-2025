Proteine werden wie Perlen auf einer Schnur nach einem vierstel-
 ligen genetischen Code aus Aminosäuren (AGCT, steht für die
 Nukleotide Adenin, Guanin, Cytosin und Thymin) zusammen-
 gesetzt, der von der DNA vorgegeben wird. Alle Zellen, die einen
 Zellkern haben, verfügen über den Code zur Herstellung aller
 Proteine, die der Korper verwendet. Aber viele Codes werden
 nie umgesetzt (exprimiert). Wenn wir sager,, dass ein bestimmter
 Zelltyp ein bestimmtes Protein »exprimiert«, meinen wir damit,
 dass es sich um einen der Zelltypen handelt, die dieses bestimmte
 Protein aus dem Code herstellen.
Einige Proteine werden konstitutionell in einem bestimmten
 Zelltyp exprimiert, was bedeutet, dass diese Zellen dieses Pro-
 tein unabhingig von den Umstinden immer mit einer bestimm-
 ten Rate synthetisieren. Zum Beispiel ist eNOS ein Enzym, das
 konstitutionell in Endothelzellen exprimiert wird, den Zellen,
 die das Innere von Blutgefifien auskleiden. Das nah verwandte
 Enzym iNOS (induzierbare NOS) wird in Immunzellen expri-
 miert, aber nur dann, wenn es durch bestimmte Umstände, zum
 Beispiel eine bakterielle Infektion, induziert wird. Wie bereits in
 Kapitel 5 erwähnt, verwenden Biologen auch den Begriff »hoch-
 reguliert« beziehungsweise das Gegenteil »herunterreguliert«. Ein
 Protein wird als Reaktion auf bestimmte Signalmolekiile, bei de-
 nen es sich oft um Zytokine handelt, hochreguliert. Das bedeutet,
 dass die Zelle die Geschwindigkeit erhöht, mit der sie dieses Pro-
 tein herstellt. Die Syntheserate eines bestimmten Proteins kann
 sich als Reaktion auf ein Signalmolekiil um das Tausendfache er-
 hohen.
